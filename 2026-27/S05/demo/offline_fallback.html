Demo 2 · From the registry to a container (slide 16)

What the terminal shows when the box built from models:/churn-model@production (version 1) is started and asked about two customers.

$ docker images churn-model
IMAGE                    ID             DISK USAGE
churn-model:production   fcaf75e62e3e   891MB

$ docker run -d -p 5002:8080 --name churn-prod churn-model:production
(a long container id)

$ curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:5002/ping
200

$ cat customers.json
{"dataframe_split": {"columns": ["tenure_months", "monthly_charges", "support_tickets"],
                     "data": [[60, 45.0, 0], [3, 110.0, 5]]}}

$ curl -s -X POST http://127.0.0.1:5002/invocations -H "Content-Type: application/json" -d @customers.json
{"predictions": [0, 1]}

$ docker rm -f churn-prod
"Zero: the loyal customer stays. One: the at-risk customer is likely to leave. A prediction from the production model, through a network request, from a box that would run the same in a bank's cloud. This is what 'deployed' means."
